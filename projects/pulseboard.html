Overview

What it is

Pulseboard is a personalised content dashboard. News, movie recommendations and mock social posts share one responsive feed. It works immediately without API keys.

One feed

News, movies and social posts in a single responsive layout.

Favourites

Save items and find them again; favourites persist.

Debounced search

Search filters the feed without hammering on every keystroke.

Drag and drop

Reorder your feed.

Dark mode

Theme toggle.

Server-side providers

NewsAPI and TMDB are called server-side when keys are set; otherwise sample data is shown.

Flow

How it works

Browse

My feed, Trending and Favorites views.

Personalise

Save items, search, and reorder with drag and drop.

Plug in real data

Add NewsAPI and TMDB keys to swap the sample data for live providers.

The live demo runs on sample data, not live provider data.

Run it

git clone https://github.com/Prajit-22/pulseboard.git cd pulseboard npm install npm run dev
