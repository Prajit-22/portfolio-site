Overview

What it is

A small security-incident tracker built in two parts. The Spring Boot REST API stores incidents, validates input, filters and paginates, and enforces a lifecycle rule. The React dashboard reads and writes that API.

API

Spring Boot with an H2 database. Create, read, filter by severity and status, paginate.

Validation

Per-field error details; bad payloads, enums and page sizes return 400.

Lifecycle rule

OPEN, INVESTIGATING, RESOLVED. A resolved incident cannot be reopened, enforced by the API and mirrored in the UI.

Summary endpoint

One call returns totals plus counts by status and severity, which powers the dashboard header.

Dashboard

React + TypeScript (Vite): triage summary bars, filterable list, report form, status changes.

Tests

15 MockMvc integration tests on the API; Vitest + Testing Library on the dashboard.

Flow

How it works

Report

Submit an incident from the dashboard form; the API validates it field by field.

Triage

Filter by status and severity and watch the summary counts update.

Resolve

Move incidents through the lifecycle; resolved ones stay locked.

No authentication: meant for local development. Run the API first, then the dashboard.

Run it

# API (Java 11+, Maven) git clone https://github.com/Prajit-22/incident-triage-api cd incident-triage-api && mvn spring-boot:run # Dashboard (Node 22+) git clone https://github.com/Prajit-22/incident-triage-dashboard cd incident-triage-dashboard && npm install && npm run dev
